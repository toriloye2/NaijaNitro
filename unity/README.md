# Naija Nitro: Lagos rebuild
Unity 6 prototype foundation. Open the unity directory in Unity Hub. Existing web game is preserved on main. This is not yet a playable scene or an APK.
Design: original Lagos free-roam driving and arcade races; fictional compact Lekki / Ikoyi / Third Mainland map. Use the existing original Blender sedan as a starting point, export FBX with separate wheel pivots, create textured city assets and collision meshes, bake lighting and use LODs for mobile.
Setup: create a scene, add a road with collider, a vehicle root with Rigidbody and collider plus ArcadeCar, then add ChaseCamera to a Camera and assign the vehicle. Legacy input axes Horizontal and Vertical are required. Touch fields are hooks, not a completed touch interface.
Acceptance: playable city route, stable collisions, mobile controls, verified build and real gameplay screenshots. No claim of GTA quality until visually validated.
