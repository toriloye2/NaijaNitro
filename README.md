# Naija Nitro 🇳🇬

A browser-based arcade racing prototype set in stylized Nigerian locations.

## Play

The hosted entry page redirects to [Lagos Asphalt](./game/). Use a static server locally (e.g. VS Code Live Server). The game loads Three.js from an external CDN.

## Controls

W/Up = accelerate; S/Down = brake; A/D or Left/Right = steer; Space = drift; Shift = nitro; P = pause; R = restart. Touch buttons appear on touch-screen devices.

## Included

- Third Mainland Sprint and Lagos Island Circuit
- Street GT, Sport Coupe and Hyper RS profiles
- 3-lap races and time trial
- Three computer-controlled opponents
- Nitro, drifting, laps, checkpoints, lap records and collisions

## Deployment

This repository is a static site. In Netlify, import the GitHub repository and use the default root publish directory. No build command is required. When Netlify auto-deploy is enabled, pushes to `main` update the website.

## Status

**v6.0.0 prototype, not production validated.** Fictional layouts, simplified custom vehicle physics and opponent logic. The game has not passed hands-on browser, performance or accessibility testing.
